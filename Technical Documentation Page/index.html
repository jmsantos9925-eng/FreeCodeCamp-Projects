Welcome

here. is a local-first web application that I developed for saving memories based on where they happened.

The application stores everything using the browser's local storage, so no account is needed.

You can try the project at heredotapplication.netlify.app.

Interface Preview

Getting Started

Open the application and start creating memories immediately.

Every memory is stored on your current browser and device.

  • Open here.
  • Create a memory.
  • Add a location.
  • Attach media.
  • Save it.
Storage: Local
Map

The Map displays every saved memory using location pins.

Selecting a pin opens the information connected to that place.

View: Map
Timeline

The Timeline organizes memories based on when they were created.

It provides another way to browse memories without using the map.

View: Timeline
Companions

Companions can be linked to memories to remember who or what was with you.

People and pets can both be added as companions.

Type: Person or Pet
Privacy and Backup

here. keeps saved memories on the user's own browser instead of using an online account.

Users can create a backup of their saved data and restore it when needed.

  • Data is stored locally.
  • No account is required.
  • Saved data can be exported.
  • Backup files can be imported.
  • The user keeps control of their own data.
Backup: Export and Import
Settings

Settings contains options for managing the application.

It also provides access to preferences related to local data.

Data: Browser Storage
About

here. is a personal web application that focuses on connecting memories with places.

The project was built using HTML, CSS and JavaScript with local storage.

The goal is to keep memories simple, organized and easy to revisit.
